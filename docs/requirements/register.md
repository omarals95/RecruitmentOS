- **Local evidence for this audit:** Node v24.20.0, `npx vitest run` → 34 files, 220 tests passed, 0 skipped. `npm run test:storage` → 52 passed. PGlite, fake storage and fake signers only. No dev server, cloud resource, network provider or real data was used.
- **Status legend:** not started | partial | locally verified | Preview verified | Production verified | blocked | deferred.
  - **locally verified:** a local automated test exercises the acceptance criterion.
  - **partial:** code exists but the criterion is not fully tested, or only part of it is built.
  - **blocked:** progress depends on an external decision or live resource.
  - **Preview verified:** the acceptance criterion is exercised on the Neon Preview database by the owner's run of `scripts/db-role-evidence.ts` and `npm run test:live-roles`; there is still no Production deployment.
  - **Production verified:** none yet, because no Production deployment exists.
- **Reading rule:** a "locally verified" row still needs hosted evidence before any release gate. PGlite cannot prove live Neon privileges, multi-connection races, provider guarantees, delivered email or real browser behaviour (SRS §13.1).
